🌐 Community Knowledge Sharing App

A collaborative platform where users share, discover, and discuss knowledge together — from bite‑sized insights to in‑depth guides.

✨ Features

🧠 Knowledge Sharing: Create and browse posts, questions, and guides across topics.

👥 Community-Focused: Upvote useful content and follow favorite contributors.

💬 Real-Time Discussion: Comment threads and notifications to keep conversations flowing

🎨 Clean, Responsive UI: Optimized for both mobile and desktop users.
